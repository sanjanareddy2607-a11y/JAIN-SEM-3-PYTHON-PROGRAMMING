# 📂 Lab Exercises

## 📝 Lab 1 – Student Information and Academic Summary

### Objective

Develop a Python program that accepts a student's personal and academic details, calculates the total and average marks, and displays the information using formatted strings.

### Concepts Covered

* User Input
* Variables
* Data Types
* Arithmetic Operations
* Formatted String Literals (f-strings)

### Features

* Accepts student details
* Accepts marks for three subjects
* Calculates total marks
* Calculates average marks
* Displays a neatly formatted student report

---

## 🧮 Lab 2 – Scientific Calculator for Two Numbers

### Objective

Develop a calculator that performs various arithmetic operations on two user-provided numbers.

### Concepts Covered

* Arithmetic Operators
* User Input
* Formatted Output

### Operations Performed

* Addition
* Subtraction
* Multiplication
* Division
* Floor Division
* Modulus
* Exponentiation (Power)

---

## 📐 Lab 3 – Mathematical Calculator using Built-in Functions and Math Module

### Objective

Develop a Python program that demonstrates mathematical operations using Python's built-in functions and the `math` module.

### Concepts Covered

* Python `math` Module
* Built-in Functions
* Mathematical Operations
* Memory Management
* Data Types

### Operations Performed

* Square
* Cube
* Square Root
* Ceiling Value
* Floor Value
* Absolute Value
* Variable Type
* Memory Address (`id()`)

---

## ⚡ Lab 4 – Electricity Bill Calculator

### Objective

Develop a Python program to calculate the electricity bill based on the given units consumed using slab-wise billing logic.

### Concepts Covered

* Conditional Statements (`if`, `elif`, `else`)
* Arithmetic Calculations
* User Input
* Decision Making

### Features

* Accepts units consumed
* Calculates bill according to slab rates
* Displays the final electricity bill
